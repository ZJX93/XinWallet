鑫钱包

个人财务助手 · Personal Finance

版本 v0.1.x

一个注重隐私与可解释性的自托管个人记账应用：多账户复式记账、预算、债务、理财、AI 智能识别记账与深度报表，数据完全掌握在自己手中。

核心特性

多账户复式记账

现金 / 银行卡 / 信用卡 / 电子支付 / 金融账户统一记账，自动对账防漂移。

AI 智能识别

一句话或截图，AI 自动归类落地；模型可复核、可回退。

预算与债务

多周期预算、贷款 / 信用卡 / 借贷全周期跟踪。

报表与洞察

专业报表、AI 消费洞察与习惯学习。

技术栈

  • 后端：Node.js + Express + PostgreSQL / MySQL（双方言）
  • 前端：原生 HTML / CSS / JS（毛玻璃 UI）+ Chart.js
  • 移动端：原生 Android（Kotlin）· 鸿蒙 HarmonyOS（ArkTS）
  • 部署：Docker 镜像，统一版本线，一键自托管
