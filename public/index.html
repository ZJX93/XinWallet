🤖 AI 服务商配置

配置大模型服务商后即可使用 AI 记账、消费洞察和语音转写。建议搭配两个服务商：一个用于对话（如 MiniMax），一个用于语音转写（如 Groq 免费 Whisper）。API Key 仅保存在服务端。

📋 快速上手
① 点击「添加服务商」→ 选择快捷预设（如 MiniMax）→ 填入 API Key → 保存
② 如需语音记账，再添加一个 Groq（免费）用于语音转写
③ 点击「启用」切换对话服务商，语音转写会自动选择支持的服务商
🤖
